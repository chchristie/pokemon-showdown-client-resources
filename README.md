Pokemon sprites are 96x96 px. 
Pokemon icons are 40x30 px. 
Make sure to include `digipenIcon: true` and `digipenSprite: true` for the Pokemon entry in the server data/mods/gen9digipen/pokedex.ts file if you want to use this resource location for the Pokemon images.  
When naming sprite or icon image files for Pokemon, use their ID but with a hyphen between the Pokemon name and its forme.

Item icons are 24x24 px.
Name the item icon image file with the same name as the item ID. 
Make sure to include `isNonstandard: "DigiPen"` for the Item entry in the server data/mods/gen9digipen/items.ts file if you want to use this resource location for the Item icon.

Trainer sprites are 80x80 px.
